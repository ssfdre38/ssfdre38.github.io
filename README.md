## Development

This is a static GitHub Pages site. To update:

```bash
git clone https://github.com/ssfdre38/ssfdre38.github.io.git
cd ssfdre38.github.io
# Edit index.html
git add .
git commit -m "Update website"
git push
```

Changes go live automatically within a few minutes.

## Domain Configuration

Custom domain `ssfdre38.xyz` is configured via CNAME file.

DNS settings should point to:
- A record: GitHub Pages IPs
- CNAME: ssfdre38.github.io
